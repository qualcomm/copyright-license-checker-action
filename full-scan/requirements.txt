# The <8.5 bound is load-bearing, not hygiene: click 8.5.0 made a flag's Option.default
# a Sentinel.UNSET, and commoncode's cliutils._is_set decides "was this option used?" with
# `value != param.default` -- so every boolean flag reads as used and scancode's
# --strip-root/--full-root mutual exclusion trips on EVERY invocation (click.UsageError,
# exit 2). Verified still required ON 32.5.0: it ships the same commoncode 32.5.2 (the latest
# release), so the bound outlived the upgrade -- drop it only once commoncode fixes _is_set.
click>=6.7,<8.5
